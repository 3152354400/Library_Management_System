# 图书馆管理系统

基于 Oracle 19c + ASP.NET Core 8 + Vue 3 的图书管理系统课程设计项目，覆盖读者服务、馆藏管理、借阅流通、读者互动与馆内空间预约等完整业务流程，前后端可独立构建并在单机环境部署运行。

## 功能

### 读者端
- 注册 / 登录 / 登出（BCrypt 加密，JWT 认证）
- 图书检索、详情、分类浏览
- 借书、还书、续借、借阅记录、未还数量查询
- 图书预约、取消预约
- 图书荐购
- 站内通知（未读数量、已读标记）
- 图书收藏（收藏夹、备注）
- 图书评论（发表、按 ISBN 查询）
- 罚金查询与缴纳（列表 / 汇总）
- 座位预约（查看座位布局、预约、取消、我的预约）
- 个人资料与头像

### 管理员端
- 登录（高级 / 普通管理员）
- 图书管理：列表、新增（自动生成条码）、下架、副本管理
- 借阅管理：全部借阅记录、借书 / 还书操作
- 丢书上报处理（列表 / 确认 / 赔偿）
- 公告管理：发布 / 列表 / 下架
- 读者管理：列表 / 详情 / 新增 / 编辑
- 罚款管理：待缴列表、缴纳、减免
- 荐购处理：待审核列表、采纳 / 拒绝
- 采购分析：借阅频次 / 借阅时长 / 副本利用率排行
- 报表：待处理举报

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Vite |
| 后端 | ASP.NET Core 8（.NET 8）、Dapper、JWT |
| 数据库 | Oracle 19c（Docker 部署） |
| 缓存 / 会话 | Redis |
| 反向代理 / 静态资源 | Nginx |

## 快速开始

部署流程（Oracle 19c 容器构建、后端 systemd 服务、Nginx 配置、数据库初始化与升级）见：

- [`deploy/单机版部署手册.md`](deploy/单机版部署手册.md) — 单机完整部署
- [`deploy/部署手册.md`](deploy/部署手册.md) — 双机（应用 / 数据库分离）部署

### 环境要求
- 服务器：Ubuntu 22.04+，4 核 8G 以上
- 软件：Docker、.NET 8 Runtime、Nginx、Redis
- 数据库：Oracle 19c

### 核心配置
- 后端端口：`5000`
- 数据库连接串键名：`OracleDB`
- 示例账号：读者 `reader001`，管理员 `LIB001`，密码 `123456`

## 数据库

共 30 张表，覆盖：读者与管理员、图书信息与馆藏副本、分类与书架、借阅与续借、罚金与缴纳、书单与收藏、评论与举报、公告、图书预约、荐购、座位 / 自习室预约、通知、采购记录、操作日志。

数据库初始化脚本见 `database/` 目录；从精简版升级到完整版的增量脚本见 `deploy/sql/upgrade_full_1.sql` 与 `deploy/sql/upgrade_full_2.sql`（需依次执行）。
