# 图书馆管理系统 · 单机部署手册

> 适用场景：一台云服务器上部署全部组件（Oracle 19c + Redis + 后端 + 前端）。
> 配套文件：`deploy/nginx.conf`、`deploy/library-api.service`。

## 一、服务器要求

| 项 | 要求 | 说明 |
|---|---|---|
| 配置 | 4 核 8G 起步 | Oracle 19c 内存占用较高，2 核 4G 不建议 |
| 系统 | Ubuntu 22.04 | |
| 系统盘 | 60G 以上 | Oracle 镜像与数据占大头 |
| 安全组 | 放行 TCP 22 / 80 / 5000 | 数据库 1521 与 Redis 6379 仅本机使用，不对公网开放 |

## 二、基础环境

```bash
sudo apt update
sudo apt install -y git unzip docker.io build-essential libaio1 libnsl2 bc nginx curl wget
sudo systemctl enable --now docker
```

## 三、Redis

```bash
sudo apt install -y redis-server
sudo systemctl enable --now redis-server
redis-cli ping        # 输出 PONG
```

修改默认密码（推荐）：编辑 `/etc/redis/redis.conf`，设置 `requirepass <密码>` 后重启：

```bash
sudo systemctl restart redis-server
```

## 四、Oracle 19c（Docker）

```bash
cd /opt
sudo git clone https://github.com/oracle/docker-images.git
cd docker-images/OracleDatabase/SingleInstance/dockerfiles

# 将 Oracle 19c 安装包 LINUX.X64_193000_db_home.zip（约 2.8GB）上传至服务器后放入 19.3.0/ 目录
sudo mkdir -p /home/oracle_install
sudo mv /home/oracle_install/LINUX.X64_193000_db_home.zip 19.3.0/

docker pull container-registry.oracle.com/os/oraclelinux:7-slim
docker tag container-registry.oracle.com/os/oraclelinux:7-slim oraclelinux:7-slim
sudo ./buildContainerImage.sh -v 19.3.0 -e        # 构建约 20~40 分钟
```

启动容器（端口仅绑定本机）：

```bash
docker volume create oradata19c
docker run -d --name oc19 --restart unless-stopped \
  -p 127.0.0.1:1521:1521 \
  -e ORACLE_PWD=<数据库密码> \
  -e ORACLE_SID=ORCLCDB \
  -e ORACLE_PDB=ORCLPDB1 \
  -e ORACLE_CHARACTERSET=AL32UTF8 \
  -v oradata19c:/opt/oracle/oradata \
  oracle/database:19.3.0-ee

docker logs -f oc19    # 等待出现 "DATABASE IS READY TO USE!"
```

创建业务用户：

```bash
docker exec -it oc19 sqlplus sys/<数据库密码>@//localhost:1521/ORCLPDB1 as sysdba
```

```sql
CREATE USER final_owner IDENTIFIED BY <业务用户密码>;
GRANT CONNECT, RESOURCE TO final_owner;
GRANT CREATE TABLE, CREATE VIEW, CREATE SEQUENCE, CREATE PROCEDURE, CREATE TRIGGER TO final_owner;
ALTER USER final_owner QUOTA 100M ON USERS;
```

建表与业务对象：按 `database/` 目录下脚本顺序执行；若基于精简版升级，依次执行 `deploy/sql/upgrade_full_1.sql`、`deploy/sql/upgrade_full_2.sql`。含中文的脚本需在 `NLS_LANG=AMERICAN_AMERICA.AL32UTF8` 环境下执行。

## 六、构建与上传

本机构建（需 .NET 8 SDK 与 Node）：

```powershell
powershell -ExecutionPolicy Bypass -File deploy\build_all.ps1
```

产物：
- `frontend/dist/` → 服务器 `/var/www/library/`
- `publish/` → 服务器 `/opt/library/`

上传前修改 `backend/appsettings.Production.json`（数据库与 Redis 均在本机，全部使用 localhost）：

```jsonc
{
  "ConnectionStrings": {
    "OracleDB": "User Id=final_owner;Password=<业务用户密码>;Data Source=localhost:1521/ORCLPDB1",
    "Redis": "localhost:6379,password=<Redis密码>"
  },
  "Jwt": { "Secret": "<64位以上随机字符串>", "Issuer": "Library_Management_System", "Audience": "all", "ExpireMinutes": 30 }
}
```

上传：

```bash
scp -r frontend/dist root@<服务器IP>:/var/www/library/
scp -r publish/*    root@<服务器IP>:/opt/library/
```

## 七、启动后端

```bash
sudo mkdir -p /opt/library /var/www/library
sudo chown -R www-data:www-data /opt/library /var/www/library
sudo cp deploy/library-api.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now library-api
sudo journalctl -u library-api -f     # 确认无数据库 / Redis 连接错误
```

## 八、配置 Nginx

将 `deploy/nginx.conf` 中的 `server_name` 改为本机 IP 后：

```bash
sudo cp deploy/nginx.conf /etc/nginx/sites-available/library.conf
sudo ln -s /etc/nginx/sites-available/library.conf /etc/nginx/sites-enabled/ 2>/dev/null
sudo nginx -t && sudo systemctl reload nginx
```

## 十、常见问题

- **页面能开、数据加载失败**：查看浏览器 F12 Network，请求 404 为 Nginx 反代未配对；500 为后端未启动或连不上数据库。
- **后端连不上 Oracle**：确认容器运行（`docker ps`）、密码正确、连接串为 localhost。
- **登录报未认证**：Redis 连接失败，执行 `redis-cli ping` 检查。
- **Oracle 镜像构建失败**：多为安装包路径或网络问题，用 `docker images` 确认镜像。
