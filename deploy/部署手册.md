# 图书馆管理系统 · 部署手册

> 适用：应用服务器与数据库服务器分离的双机部署。
> 配套文件：`deploy/nginx.conf`、`deploy/library-api.service`、`deploy/build_all.ps1`。

## 一、部署前准备

1. 数据库（final_owner）与 Redis 密码、JWT Secret 部署时全部改为随机长字符串，同步更新 `backend/appsettings.Production.json`。
2. 安全组放行：应用服务器放行 80（Web）、5000（后端 API，若走 Nginx 反代可不对外）、22；数据库服务器放行 1521、6379 时仅允许应用服务器 IP 访问。
3. 数据库脚本在数据库服务器执行一套（详见 database 目录说明）。

## 二、本机构建（Windows）

前置：Node 22+、.NET 8 SDK。

```powershell
cd <项目根目录>
powershell -ExecutionPolicy Bypass -File deploy\build_all.ps1
```

产物：
- `frontend/dist/` → 应用服务器 `/var/www/library/`
- `publish/` → 应用服务器 `/opt/library/`

## 三、应用服务器准备

```bash
sudo apt update
sudo apt install -y nginx

# .NET 8 Runtime
wget https://packages.microsoft.com/config/ubuntu/22.04/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
sudo apt update
sudo apt install -y dotnet-runtime-8.0

sudo mkdir -p /var/www/library /opt/library
```

## 四、上传并启动后端

上传前修改 `backend/appsettings.Production.json`：

```jsonc
{
  "ConnectionStrings": {
    "OracleDB": "User Id=final_owner;Password=<数据库密码>;Data Source=<数据库服务器IP>:1521/ORCLPDB1",
    "Redis": "<数据库服务器IP>:6379,password=<Redis密码>"
  },
  "Jwt": { "Secret": "<64位以上随机字符串>", "Issuer": "Library_Management_System", "Audience": "all", "ExpireMinutes": 30 }
}
```

```bash
# 本机执行
scp -r publish/* root@<应用服务器IP>:/opt/library/

# 服务器执行
sudo chown -R www-data:www-data /opt/library
sudo cp deploy/library-api.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now library-api
sudo journalctl -u library-api -f     # 确认无数据库 / Redis 连接错误
```

## 五、上传前端并配置 Nginx

```bash
# 本机执行
scp -r frontend/dist/* root@<应用服务器IP>:/var/www/library/

# 服务器执行
sudo cp deploy/nginx.conf /etc/nginx/sites-available/library.conf
sudo ln -s /etc/nginx/sites-available/library.conf /etc/nginx/sites-enabled/ 2>/dev/null
sudo nginx -t && sudo systemctl reload nginx
```

前端统一走同域相对路径（`/api`、`/avatars/`），由 Nginx 反向代理，不跨端口直连。

## 六、验证

| 项 | 验证方式 | 预期 |
|---|---|---|
| 网站 | 浏览器访问 `http://<应用服务器IP>` | 出现登录页 |
| 注册 / 登录 | 注册新读者并登录 | 跳转首页 |
| 借书 / 还书 | 搜索图书 → 借阅 → 还书 | 状态流转正常 |
| 扩展功能 | 预约 / 荐购 / 座位 / 采购分析页面 | 正常打开 |
| 实时通知 | 管理员发公告 | 读者端弹出通知 |
| 后端健康 | `curl http://127.0.0.1:5000/api/announcements/public` | 返回 JSON |
| 定时任务 | `journalctl -u library-api` | 每小时有逾期提醒执行记录 |

## 七、安全收尾

1. 敏感配置（`appsettings.Production.json` 等）不提交仓库，仓库内仅保留脱敏示例 `backend/appsettings.Production.example.json`。
2. 部署完成后轮换数据库 / Redis 密码并确认功能正常。
3. 本手册与 nginx.conf、systemd 服务、构建脚本均位于 `deploy/` 目录。

## 八、常见问题

- **打不开网站**：安全组 80 未放行或 Nginx 未启动 → `systemctl status nginx`。
- **页面能开但数据加载失败**：F12 查看 Network，404 为 Nginx `/api` 反代未配对；500 为后端未启动或连不上库。
- **登录提示未认证**：Redis 连接失败，检查 Redis 密码 / 端口。
- **定时任务日志报 ORA-00920**：使用 dev 分支修复后的代码重新发布。
- **WebSocket 连不上**：检查 Nginx `/api/ws/` 配置段，前端连接需携带 `?token=`。
