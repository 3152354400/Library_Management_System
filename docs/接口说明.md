# 后端接口说明

后端接口统一挂在 `/api` 下，前端通过 `frontend/src/api/` 下的模块调用（http 服务已带 `/api` 前缀）。除登录注册和公开查询外，大部分接口需要请求头带 JWT，登录接口返回的 token 存本地后随请求携带。下面的清单按模块分组，路径以 `/api` 开头，`{}` 为路径参数。

## 认证（AuthController）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/login | 登录，body 传 userName/password/userType，返回 token |
| POST | /api/register | 注册读者账号 |
| POST | /api/logout | 登出 |

## 说明

- 图书相关的接口中，`Book`（副本，有条码和借出状态）和 `BookInfo`（书目，按 ISBN）是两个表，注意区分：搜索和详情走 ISBN，借还和条码走副本。
- 管理员身份在登录时用 userType=librarian 区分，读者为 reader。
- 完整表结构见仓库根目录《21组-图书馆管理系统-数据库设计文档.doc》和 `database/` 下的建表脚本。
