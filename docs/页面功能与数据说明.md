# 页面功能与数据说明

这份文档给新加入的同学看，说明线上每个页面是干什么的、主要调哪些接口、读写哪些表。路由前缀 `/reader` 需要读者登录，`/admin` 需要管理员登录，其余是公开页面。前端页面代码在 `frontend/src/modules/` 下，按 home / reader / admin 三个模块分。

## 公开页面

| 路由 | 页面 | 功能 | 主要接口 | 主要表 |
|---|---|---|---|---|
| / | 首页 | 馆藏数据展示（馆藏量、座位数等）、公告、热门图书 | GET /api/stats、GET /api/announcements/public | BookInfo、Seat、Announcement |
| /books | 图书分类 | 分类树浏览，点分类看该分类下的书 | GET /api/Category/tree、GET /api/BookCategory/category/{id} | Category、Book_Classify、BookInfo |
| /book/:isbn | 图书详情 | 书目信息、副本状态、分类、评分、评论、收藏/预约/借阅入口 | GET /api/Book/detail/{isbn}、GET /api/Comment/search、POST /api/reader/favorite、POST /api/reader/extension/reserve | BookInfo、Book、Comment_Table、BookFavorite、ReserveBook |
| /search | 搜索 | 按关键词搜书 | GET /api/Book/search | BookInfo |
| /announcements | 公告 | 公开公告列表 | GET /api/announcements/public | Announcement |
| /auth | 登录/注册 | 读者注册、读者/管理员登录 | POST /api/register、POST /api/login | Reader、Librarian |

## 数据表清单

下面是库里主要的表，按业务分一下，方便查数据时定位：

**账号与基础**
- Reader：读者（昵称、密码哈希、头像、状态）
- Librarian：管理员（分高级/普通）

**图书与馆藏**
- BookInfo：书目（ISBN、书名、作者、出版社、分类、简介、封面）
- Book：图书副本（条码、所属书架、借出状态），一条 BookInfo 有多本 Book
- Category：图书分类（树形）
- Book_Classify：图书与分类的关联表
- Bookshelf：书架（楼栋、楼层、区域、编号）

**流通**
- BorrowRecord：借阅记录（读者、副本、借期、应还、实还、状态）
- RenewRecord：续借记录
- ReserveBook：图书预约
- Fine：罚款（类型、金额、缴纳状态）
- FinePayment：罚款缴纳记录
- BookLossReport：丢书上报

**互动**
- BookFavorite：图书收藏（分组、备注）
- Booklist：书单（名称、简介、创建人、是否公开）
- Booklist_Book：书单里的图书
- Collect：收藏的书单（含收藏备注）
- Comment_Table：图书评论
- Report：评论举报

**空间**
- Building：楼栋
- StudyRoom：自习室
- Seat：座位（所属自习室/楼层）
- Reserve_Seat：座位预约
- Reserve_Room：自习室预约

**其他**
- Announcement：公告
- RecommendPurchase：图书荐购
- Notification：通知
- PurchaseLog：采购日志
- OperationLog：操作日志
- Log：系统日志

## 几个容易混淆的点

- 图书有两层：**BookInfo（书目）** 和 **Book（副本）**。搜索、详情、分类都是书目；借还、条码、书架是副本。改借阅相关功能时先分清操作的是哪一层。
- 座位和自习室也是两套：Seat 是具体座位，Reserve_Seat 是座位预约；StudyRoom/Reserve_Room 是自习室那套，目前页面主要用的是座位。
- 前端 `src/modules/` 下有一些旧页面文件（带 ManagePage、AdminPage 后缀的），线上路由并没有引用它们，改功能以 `src/router/index.js` 里注册的页面为准。
